# Code de conduite

Ce code de conduite est adapté du [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

## Notre engagement

En tant que membres, contributeurs et responsables, nous nous engageons à faire de la participation à ce projet
une expérience sans harcèlement pour tous, quels que soient l'âge, l'apparence, le handicap, l'origine,
l'identité ou l'expression de genre, le niveau d'expérience, la nationalité, la religion ou l'orientation sexuelle.

## Comportements attendus

- Faire preuve de bienveillance et de respect envers les autres.
- Respecter les opinions, points de vue et expériences différents.
- Donner et recevoir des critiques constructives, sur le code et non sur les personnes.
- Reconnaître ses erreurs, s'en excuser et en tirer des leçons.
- Privilégier ce qui est le mieux pour le projet et l'équipe.

## Comportements inacceptables

- Les propos ou images à caractère sexuel, et toute attention ou avance non sollicitée.
- Les commentaires insultants ou désobligeants, et les attaques personnelles ou politiques.
- Le harcèlement, public ou privé.
- La publication d'informations privées d'autrui sans son accord explicite.
- Tout autre comportement qui serait jugé inapproprié dans un cadre professionnel.

## Responsabilités et application

Les responsables du projet clarifient et font respecter ces règles. Ils peuvent retirer ou modifier les
commentaires, commits, code ou issues qui ne les respectent pas, et exclure temporairement ou définitivement
un contributeur.

Tout comportement inacceptable peut être signalé aux responsables du projet, en message privé sur GitHub
ou auprès de l'équipe pédagogique. Les signalements sont traités rapidement, de façon équitable et confidentielle.

## Portée

Ce code s'applique dans tous les espaces du projet (dépôt, issues, pull requests, revues de code, échanges
d'équipe) et lorsqu'une personne représente le projet publiquement.
